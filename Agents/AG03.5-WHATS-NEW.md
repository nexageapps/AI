### Before AG03.5
```python

    """Transfer money between accounts."""
    # What if accounts don't exist? ❌
    # What if insufficient funds? ❌
    # What if network fails? ❌
    # How fast does this run? ❓
    # Is it being called too often? ❓
    return f"Transferred ${amount}"
```

**Problems:**
- ❌ No validation
- ❌ No error handling
- ❌ No retry logic
- ❌ No rate limiting
- ❌ No metrics
- ❌ Silent failures

### After AG03.5
```python
@tool
@instrumented_tool
@safe_tool_execution
@retry_with_backoff(max_retries=3)
def transfer_money(
    from_acct: int = Field(gt=0, description="Source account"),
    to_acct: int = Field(gt=0, description="Destination account"),
    amount: float = Field(gt=0, le=10000, description="Amount (max $10k)")
) -> Dict[str, Any]:
    """Transfer money with validation and error handling."""
    
    # Rate limiting
    if not transfer_limiter.allow_call():
        raise RateLimitError("Max 10 transfers/min")
    
    # Validate accounts
    if not account_exists(from_acct):
        raise AccountNotFoundError(f"Account {from_acct} not found")
    
    # Check funds
    if get_balance(from_acct) < amount:
        raise InsufficientFundsError(f"Need ${amount}, have ${get_balance(from_acct)}")
    
    # Execute transfer
    result = execute_transfer(from_acct, to_acct, amount)
    
    return {
        "success": True,
        "transaction_id": result.id,
        "new_balance": get_balance(from_acct)
    }
```

**Improvements:**
- ✅ Schema validation with Pydantic
- ✅ Structured error handling
- ✅ Automatic retry on transient failures
- ✅ Rate limiting (10 transfers/min)
- ✅ Metrics tracking (duration, errors)
- ✅ Clear error messages for agent
