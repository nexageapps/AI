## Content Highlights

### AG01 - Introduction to AI Agents ✅
**Covered:**
- What are AI agents vs simple LLM calls
- The ReAct (Reasoning + Acting) pattern
- Agent capabilities: memory, tools, planning, self-correction
- When to use agents vs chains vs simple prompts
- Real-world examples (customer support, data analysis, code assistant)
- Limitations and failure modes
- Ethical considerations
- Quick quiz for understanding

**Visual diagrams for:**
- ReAct loop flow
- Decision tree for choosing agent vs LLM
- Comparison table

### AG02 - LangChain Basics ✅
**Covered:**
- Complete installation and setup guide
- LLM wrappers and chat models
- Streaming responses
- Prompt templates (basic, chat, few-shot)
- Output parsers (String, JSON, Pydantic)
- LCEL chains with `|` operator
- Sequential, parallel, and fallback chains
- Complete sentiment analysis application
- Token counting and cost monitoring
- Multi-provider support (OpenAI, Anthropic, Google, local)
- Practice exercises with solutions

**Runnable code cells for:**
- All concepts with real API calls
- Progressive complexity
- Production patterns
