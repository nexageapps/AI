# Agents: Systems that decide and act

> **15 lessons · ≈ 47 hours** · Question: *How do I build systems where the model decides and acts?* · Exit test: you can **build, test, trace and deploy a tool-using multi-step agent**.
> *This README is generated by `tools/gen_readmes.py` from the files on disk; status is detected, not hand-typed.*

The core of this repository. You start by writing the agent loop yourself (AG02), then add tools, planning, memory, retrieval, workflow patterns, orchestration, guardrails, MCP, multiple agents, coding and computer-use agents, and finish with evaluation, observability and a shipped capstone.

**Two ways to run every lesson (same code):**

| Mode | How | Cost |
|---|---|---|
| **OFFLINE** (default) | no setup; the model's turns are a recorded script, tools and assertions run for real | free |
| **LIVE** | `export ANTHROPIC_API_KEY=...` then run the notebook; the same loop calls Claude | pay per token |

Shared helper code lives in [`agentkit/`](../agentkit) (about 400 lines, readable in an hour).

## Learning path

```
AG01 what is an agent ─ AG02 the loop ─ AG03 tools ─ AG04 planning ─ AG05 memory ─ AG06 agentic RAG
        └──────── single-agent foundations ────────┘
AG07 workflow patterns ─ AG08 graphs/durability ─ AG09 humans & guardrails ─ AG10 MCP
        └──────── orchestration & integration ─────┘
AG11 multi-agent ─ AG12 coding agents ─ AG13 computer use ─ AG14 eval & observability ─ AG15 capstone
        └──────── advanced systems & shipping ─────┘
```

**Design principles taught throughout:** start with the simplest thing that works (a single call, then a workflow, then an agent); enforce invariants in code, not prompts; keep a trace of everything; measure before you tune; keep a human in the loop for irreversible actions.

## How to work through a lesson

1. Read **Why this matters** and the **objectives**, then predict what the code will do before running it.
2. Run top to bottom; *change something* in every cell (a parameter, a prompt, a tool) and note what breaks.
3. Do **Practice** exercises always, **Stretch** if you want depth, **Challenge** if you want to be hired.
4. Answer the **Checkpoint** from memory *before* opening the answers.
