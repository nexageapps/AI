## How to work through a lesson

1. Read **Why this matters** and the **objectives**, then predict what the code will do before running it.
2. Run top to bottom; *change something* in every cell (a parameter, a prompt, a tool) and note what breaks.
3. Do **Practice** exercises always, **Stretch** if you want depth, **Challenge** if you want to be hired.
4. Answer the **Checkpoint** from memory *before* opening the answers.
