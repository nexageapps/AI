# Security policy

Please report vulnerabilities privately. Do not open a public issue.

Use **Report a vulnerability** on this repository's Security tab (GitHub private vulnerability reporting). That keeps the report visible only to maintainers until it is disclosed.

The supported version is the latest commit on `main`. Older commits are not patched separately.

I will try to respond and fix confirmed issues, but this is a best-effort personal project and there is no promised response time or SLA.
