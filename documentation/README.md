## 🚀 Quick Start Guides

### For New Learners
1. Read [Main README](../README.md)
2. Review [Learning Sequence](../LEARNING_SEQUENCE.md)
3. Choose a [Learning Path](learning-paths/)
4. Start with Prerequisites or Basic level

### For Existing Learners (Migration)
1. Read [Comprehensive Implementation Guide](planning/COMPREHENSIVE_2026_IMPLEMENTATION_GUIDE.md) - Part 5 (Migration)
2. Check your current level
3. Add recommended new lessons
4. Continue your journey

### For Stanford Students
1. Review [Stanford Course Alignment](stanford-alignment/)
2. Map your course to our lessons
3. Use as supplementary material
4. Follow [Student Guide](MAI_STUDENT_GUIDE.md)

### For Developers Building Agents
1. Start with [Agents Expansion Plan](planning/AGENTS_2026_EXPANSION_PLAN.md)
2. Review [Agent Frameworks Comparison](frameworks/AGENT_FRAMEWORKS_2026.md)
3. Follow [Agentic AI Specialist Path](learning-paths/AGENTIC_AI_SPECIALIST_PATH.md)
4. Build from [Applications sector](../06-Applications/)
